# Grainulation Homebrew

Shared Homebrew recipes for [Irrigator](https://github.com/grainulation/irrigator)
and [Grainulator](https://github.com/grainulation/grainulator).

Formula additions are reviewed separately from application source changes.
A recipe is promoted only after its immutable release archives exist and pass
their application's installed-artifact checks. Repository initialization does
not publish an application release.
