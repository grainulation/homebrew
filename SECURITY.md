# Security

For a sensitive formula or installation-integrity issue, use this repository's
[Security tab](https://github.com/grainulation/homebrew/security) and choose
**Report a vulnerability**. Include the tap revision, formula/version, platform
and a minimal redacted reproduction. Do not post credentials or private run data.

Vulnerabilities in the applications themselves belong with
[Irrigator](https://github.com/grainulation/irrigator/security) or
[Grainulator](https://github.com/grainulation/grainulator/security).
Ordinary recipe fixes and updates use the [maintenance guide](docs/MAINTAINING.md).
